# Auto-Commit Workspace Rule

Whenever working in this repository:
1. **Auto-commit**: At the conclusion of addressing any user request or completing a set of verified code changes, automatically stage and commit all modified and newly created files using `git add` and `git commit -m "<descriptive message>"` on the current working branch.
2. **Never Merge or Push**: Under no circumstances should you run `git merge`, `git rebase`, `git push`, or alter remote branches unless the user explicitly and directly instructs you to do so.
