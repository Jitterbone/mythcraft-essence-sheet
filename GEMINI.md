# Antigravity Assistant Rules for MythCraft Essence Sheet

- **Auto-Commit**: After completing and verifying code modifications for a task, automatically stage and commit the changes to git on the active branch (`git add .` and `git commit -m "..."`).
- **No Merge or Push**: Do NOT merge branches (e.g. into `main`) and do NOT push changes to any remote (`git push`) unless explicitly requested by the user.
